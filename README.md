# SimpleClicker

シンプルなマウス連打(オートクリッカー)ツールです。Windows Forms(.NET 10)製。

![screenshot](docs/screenshot.png)

## 機能

- **左 / 右クリックの選択** — 連打するマウスボタンを選べます
- **クリック間隔の設定** — 10〜60000ms(既定 100ms)
- **動作モード**
  - 押している間 — ホットキーを押している間だけ連打
  - トグル — ホットキーを押すたびに開始 / 停止を切り替え
- **ホットキーのキャプチャ設定** — 「設定」ボタンを押してキーを入力するだけで割り当て。マウスのサイドボタン(XButton1 / XButton2)にも対応
- **開始 / 停止ボタン** — ホットキーを使わずに操作可能
- **カーソル位置の保持**(任意)— 連打開始時のカーソル位置を記憶し、連打中はその位置でクリックし続けます
- **緊急停止** — カーソル位置保持中にクリック先のウインドウが変わる(閉じる・別ウインドウが手前に来るなど)と自動停止します。再開するには一度停止操作(停止ボタン、またはホットキーによる停止)が必要です
- **連打中の目印表示**(任意)— 連打中はカーソルの近くに赤い目印を表示(クリック透過)
- **設定の自動保存** — 変更のたびに実行ファイルと同じフォルダの `settings.json` へリアルタイム保存し、次回起動時に復元します

## 使い方

1. `SimpleClicker.exe` を起動します
2. クリックするボタン(左 / 右)、クリック間隔、動作モードを設定します
3. ホットキーを変更する場合は「設定」ボタンを押し、割り当てたいキーまたはマウスのサイドボタンを押します(既定: `F6`)
4. ホットキーまたは「開始」ボタンで連打を開始します
   - 押している間モード: ホットキーを押している間だけ連打します
   - トグルモード: ホットキーを押すたびに開始 / 停止が切り替わります

ホットキーはグローバルに動作するため、アプリが非アクティブでも使用できます。

## 動作環境

- Windows 10 / 11
- [.NET 10 ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0)(Windows Desktop)

## ビルド

```
git clone https://github.com/kttFox/SimpleClicker.git
cd SimpleClicker
dotnet build SimpleClicker/SimpleClicker.csproj -c Release
```

Visual Studio でビルドする場合は `SimpleClicker.slnx` を開いてください。

## 注意事項

- 設定ファイル(`settings.json`)は実行ファイルと同じフォルダに保存されます。`Program Files` など書き込み権限のない場所に配置した場合、設定は保存されません
- 本ツールの使用は自己責任でお願いします。ゲーム等では利用規約により自動操作が禁止されている場合があります
